# Курсовая работа: Парсер вакансий с HeadHunter

## Описание проекта

Данный проект представляет собой приложение для поиска и анализа вакансий с платформы HeadHunter (hh.ru). Программа позволяет:

- Получать вакансии по поисковому запросу
- Фильтровать вакансии по ключевым словам в описании
- Сортировать вакансии по уровню зарплаты
- Просматривать топ-N вакансий по зарплате
- Сохранять информацию о вакансиях в JSON-файл

## Установка и запуск

### Требования

- Python 3.8 или выше
- pip (менеджер пакетов Python)

### Установка зависимостей

1. Установите необходимые пакеты:

```bash
cmd.exe /c "pip install requests"
```

1. Запустите приложение:


## Использование

После запуска программы вы увидите интерактивное меню с следующими шагами:

1. **Введите поисковый запрос** - введите ключевое слово или фразу для поиска вакансий (например, "Python developer", "аналитик данных", "менеджер проектов")

2. **Введите количество вакансий для вывода в топ N** - укажите число, сколько вакансий с самой высокой зарплатой вы хотите увидеть (например, 5, 10)

3. **Введите ключевые слова для фильтрации вакансий** - введите слова через пробел, которые должны содержаться в названии или описании вакансии (например, "удаленно опыт" для поиска удаленных вакансий с требованием опыта)

4. **Введите диапазон зарплат** - укажите диапазон зарплат в формате "минимальная - максимальная" (например, "100000 - 150000")

Программа выполнит поиск, отфильтрует и отсортирует вакансии, а затем выведет результаты в удобном для чтения формате.

## Особенности реализации

- **Абстрактные классы**: Использованы для определения контрактов API и файлового менеджера
- **Инкапсуляция**: Приватные атрибуты в классе Vacancy с контролируемым доступом через property
- **Валидация данных**: Проверка корректности данных при создании вакансии
- **Сравнение вакансий**: Реализованы магические методы для сравнения по зарплате
- **Гибкая фильтрация**: Возможность фильтрации по нескольким критериям
